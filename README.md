# ArvoliO

A modern meeting app with swipe matching, real-time chat, and like notifications.

## Features

- Swipe cards with like/pass
- Send messages with likes
- Real-time chat with read receipts
- Liked You section with accept/decline
- Profile setup with photo uploads
- Age and gender preferences
- Block users and remove matches
- Desktop notifications
- Mobile-first design

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Firebase (Auth, Firestore)
- Framer Motion
